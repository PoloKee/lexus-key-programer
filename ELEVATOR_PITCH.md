# Polo Forge — Elevator Pitch

Polo Forge is a text-to-music generation studio that lives in this repository. Inspired by modern AI music platforms, it runs a multi-stage audio pipeline — instrumental generation, vocal synthesis, lyrics, and stems — so a prompt becomes a full track instead of a loop. It is built as a production-ready web studio: describe the song you hear in your head, and the pipeline composes, sings, and separates it into parts you can work with. For creators who write with words first, Polo Forge turns description into music.

**Tagline:** Type it, hear it — a text-to-music studio in your browser.
